# Claude Code를 더 야심 차게 쓰는 법 — 실습 프롬프트

유튜브 영상 「Anthropic 엔지니어가 Claude Code를 쓰는 법」에서 실제로 입력한 프롬프트 모음이에요.

- 원래 글: Felix Rieseberg, [How to be more ambitious: A tutorial for humans with models](https://felixrieseberg.com/how-to-be-more-ambitious-a-tutorial-for-humans-with-models/) (2026-10-13)
- 시연 프로젝트: [ComfySims](https://github.com/dante01yoon/ComfySims)
- 프롬프트 원문: [PROMPTS.md](PROMPTS.md)

| 방법 | 한 줄 요약 |
|---|---|
| 고도 | 할 일에 「이걸로 무엇을 이루고 싶은지」 목표 한 줄을 붙인다 |
| 깊이 | 깊이 프롬프트로 다시 쓰게 하고, 만든 모델 말고 바깥 심판(Codex CLI·독립 구현·테스트)이 확인하게 한다 |
| 범위 | 하는 일을 명사 말고 동사로 말해 주고, 분야마다 서브에이전트가 차례로 보고 고치게 한다 |
| 자원 | 클로드가 볼 수 있게(화면 찍기) · 알 수 있게(스펙·결정 기록) · 확인할 수 있게(테스트) |
